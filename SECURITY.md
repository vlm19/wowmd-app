# Security Policy

## Supported version

Security fixes are applied to the current `main` branch and the currently
deployed wowMD website.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing an exploit, proof-of-concept, credentials, or
private user data. If private reporting is unavailable, open a minimal public
issue requesting a private contact channel, without technical details.

Reports are most useful when they include the affected path or component,
reproduction steps, impact, and a safe proof-of-concept. We will acknowledge
receipt, investigate, and coordinate disclosure before publishing a fix.

## Scope

Relevant areas include Markdown rendering and sanitization, browser storage,
the GitHub import flow, static-site dependencies, and Cloudflare Pages
Functions. Do not send real Markdown documents, annotations, access tokens, or
other sensitive data in a report.
