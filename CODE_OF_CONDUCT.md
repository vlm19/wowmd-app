# Code of Conduct

We want wowMD's community to be constructive, respectful, and welcoming.
Harassment, discrimination, threats, doxxing, or deliberate disruption are not
acceptable in project spaces.

Project maintainers may remove content or contributions that violate these
expectations. To report conduct concerns, use the private reporting path in
[SECURITY.md](SECURITY.md) and state that the report concerns community conduct.
