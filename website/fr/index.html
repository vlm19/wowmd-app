Fonctionnalités

De petites fonctions, toutes au service de la lecture.

Plan en premier

Commencez par la structure du document avant d’entrer dans le texte.

Sections repliables

Repliez les grandes sections H2 une par une lorsque le document devient long.

Code lisible

Les blocs de code restent lisibles grâce à un espacement clair et à la coloration.

Défilement horizontal des tableaux

Les tableaux larges défilent horizontalement sans casser la mise en page.

Apparition ciblée

Sur les README courts et les pages simples, wowMD reste invisible.

Rendu propre

Corrige les chemins d’images relatifs courants et sécurise le Markdown rendu.

Périmètre

Conçu pour GitHub Markdown, sans promettre le reste.

Pris en charge

  • Pages README de dépôts GitHub publics
  • Pages de fichiers .md publics sur GitHub
  • Pages de fichiers .markdown publics sur GitHub
  • Panneau latéral et lecteur plein écran

Non pris en charge pour le moment

  • Dépôts privés
  • Sites en dehors de GitHub
  • Issues, pull requests ou pages wiki
  • Résumés IA, traduction ou synchronisation cloud

Confidentialité

Un outil de lecture n’a pas besoin de vos données.

Aucune collecte d’informations personnelles.

Aucun envoi de documents vers des services tiers.

Aucun résumé IA, analyse cloud ou configuration distante.

Aucun accès à l’historique, aux cookies, aux informations de compte ou aux fichiers locaux.

Aucune requête Raw Markdown ou GitHub API avant votre clic sur Better View.
