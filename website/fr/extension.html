GitHub Markdown,

L'extension ouvre les pages GitHub Markdown prises en charge dans un lecteur plus calme avec plan, pliage, code lisible et tableaux défilables. Elle est volontairement limitée à Ouvrir et Lire.

Fonctionnalités

Tout ici a une seule mission : mieux lire GitHub.

Ouvrir GitHub Markdown

Fonctionne sur les pages README de dépôts publics pris en charge et les pages de fichiers .md ou .markdown.

Navigation par plan

Utilisez la structure des titres pour comprendre et parcourir les longs documents.

Pliage de sections

Repliez les grandes sections quand vous n'avez besoin que de la partie que vous lisez actuellement.

Code et tableaux

Coloration syntaxique, espacement lisible et défilement horizontal des tableaux rendent les documents techniques utilisables.

Périmètre

Périmètre précis, aucune promesse floue.

Pris en charge

  • Pages README de dépôts GitHub publics
  • Pages de fichiers .md et .markdown GitHub publics
  • Vue lecteur avec plan, pliage, code et tableaux

Non inclus dans l'extension

  • Fichiers locaux
  • Annotations, Carte de compréhension, versions ou export
  • Issues, pull requests, pages wiki ou sites non GitHub

Confidentialité

Un lecteur ne devrait pas avoir besoin de vos données.

Aucune collecte d'informations personnelles.

Aucun téléversement de documents vers des services tiers.

Aucun résumé IA, analyse cloud ou configuration à distance.

Besoin de plus ?

Besoin de fichiers locaux, d'annotations typées, de la Carte de compréhension ou d'export ?

wowMD Pro ajoute le flux de relecture complet en local. L'extension reste concentrée sur la lecture GitHub.
