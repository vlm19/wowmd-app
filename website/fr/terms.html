Résumé simple

Produits et périmètre

wowMD comprend une extension Chrome gratuite pour les pages Markdown GitHub publiques prises en charge, et wowMD Pro, une application web locale pour la lecture Markdown locale, quatre types d'annotations, une carte de révision globale, le réancrage inter-versions et quatre formats d'exportation (HTML, Markdown révisé pour Obsidian, JSON de sauvegarde, JSON de ticket). Les deux sont gratuits pendant la bêta. Les fonctionnalités peuvent évoluer avec le produit.

Fichiers locaux et contenu utilisateur

Vous êtes responsable des fichiers Markdown, annotations, notes, copies révisées et exportations que vous ouvrez ou créez avec wowMD. L'application traite les documents et les annotations localement dans votre navigateur en utilisant le stockage de données de site (IndexedDB). wowMD ne modifie pas vos fichiers sources et n'applique pas les suggestions de remplacement. Vous devez conserver des sauvegardes des fichiers importants, des annotations et du contenu exporté. La suppression des données de site du navigateur, l'utilisation de la navigation privée ou la récupération d'espace de stockage du navigateur peuvent entraîner une perte de données.

Formats d'exportation

wowMD Pro propose quatre formats d'exportation, tous générés localement dans votre navigateur : (1) HTML — un fichier autonome avec structure, surlignages et notes, pour partager la lecture annotée avec des personnes ; (2) Markdown révisé — une nouvelle copie .md avec des callouts de révision lisibles par Obsidian, des étiquettes et des propriétés, sans modifier le fichier original ; (3) JSON de sauvegarde — données d'annotation brutes pour sauvegarde ou réimportation, entièrement portables sous votre contrôle ; (4) JSON de ticket — un instantané du document, une légende des types, le contexte de section, des notes et des suggestions de remplacement, conditionnés comme un ordre de travail pour une révision assistée par IA. Les exportations sont sous votre responsabilité une fois téléchargées ou partagées.

Stockage et perte de données

wowMD Pro stocke les annotations, les empreintes de documents, les copies de documents importés, l'historique des versions et les préférences dans les données de site du navigateur (IndexedDB). Ces données sont locales à votre navigateur et ne sont ni synchronisées entre appareils ni sauvegardées sur un serveur. La suppression des données de site du navigateur, le passage à un autre navigateur ou profil, l'utilisation de fenêtres privées/incognito ou la récupération d'espace de stockage du navigateur peuvent supprimer définitivement vos annotations et votre historique des versions. Exportez régulièrement un JSON de sauvegarde pour protéger votre travail.
