Politique de confidentialité

Dernière mise à jour : 6 juin 2026

wowMD comprend une extension Chrome locale pour lire les pages Markdown GitHub publiques et wowMD Pro, une application web locale pour réviser, annoter et exporter des fichiers Markdown.

Résumé simple

wowMD conserve les documents Markdown et les annotations dans votre navigateur. Le site utilise Google Analytics et les commentaires envoyés volontairement sont transmis à wowMD. wowMD ne vend pas les données de documents ou d'annotations.

Responsable du traitement

Pour toute question relative à la confidentialité concernant wowMD, contactez le responsable via le formulaire de retour disponible sur ce site.

Données que nous traitons

L'extension lit le contenu des pages localement dans votre navigateur uniquement lorsque vous choisissez Better View. wowMD Pro lit les fichiers .md locaux que vous ouvrez et stocke les annotations localement. Aucun des deux produits ne téléverse vos documents Markdown ou annotations. Le site utilise Google Analytics, qui peut traiter les URL de pages, les identifiants de navigateur ou d'appareil et les cookies conformément à la politique de confidentialité de Google.

Finalité et base légale

Le traitement de l'extension est limité aux fonctions de lecture que vous demandez : navigation par plan, pliage de sections, rendu de code et mise en page de tableaux. Le traitement de Pro est limité aux fonctions de révision que vous utilisez : lecture structurée, quatre types d'annotations, une carte de révision globale, réancrage inter-versions et les formats d'exportation que vous choisissez. Lorsque le RGPD s'applique, cela repose sur la fourniture du service demandé et l'intérêt légitime à exploiter un outil de navigation respectueux de la vie privée.

Stockage et conservation

wowMD ne maintient pas de base de données distante pour les activités de lecture ou de révision. L'extension traite les pages temporairement dans la session du navigateur, et wowMD Pro stocke les annotations, empreintes de documents, versions et paramètres dans les données de site du navigateur (IndexedDB). Les commentaires sont stockés dans Cloudflare D1 et comprennent le message envoyé, les préférences de fonctionnalités, l'adresse e-mail facultative, l'URL de page, l'agent utilisateur et un hachage dérivé de l'adresse IP et de l'agent utilisateur. Les commentaires sont conservés jusqu'à leur suppression par le responsable.

Partage et tiers

wowMD ne vend ni ne partage les données de lecture ou d'annotation. Les exportations sont générées localement lorsque vous les initiez. Google Analytics est fourni par Google, et les commentaires du site sont traités et stockés par Cloudflare. Les informations de commentaires servent uniquement à lire les commentaires et à suivre les fonctionnalités demandées.

Données stockées localement par wowMD Pro

wowMD Pro stocke les données suivantes dans les données de site de votre navigateur (IndexedDB), jamais sur un serveur distant : les annotations que vous créez (type, note, suggestion de remplacement, contexte), les empreintes de documents utilisées pour le réancrage inter-versions, les copies de documents importés pour révision, l'historique des versions et vos préférences (thème, taille de police, mise en page). Ces données restent dans votre navigateur sauf si vous choisissez de les exporter.

Exportations Pro et vos données

Toutes les exportations sont générées localement dans votre navigateur lorsque vous les initiez. L'exportation HTML inclut le Markdown rendu avec vos surlignages et notes visibles. Le Markdown révisé inclut vos annotations sous forme de callouts Obsidian dans un nouveau fichier .md. Le JSON de sauvegarde contient vos données d'annotation brutes pour sauvegarde ou réimportation. Le JSON de ticket inclut un instantané complet du document, vos annotations et le contexte de section — examinez ce contenu avant de le partager avec une IA ou un tiers.

Chrome Web Store et utilisation limitée

wowMD utilise les autorisations du navigateur uniquement pour fournir les fonctionnalités de lecture divulguées. Les informations reçues des API Google, le cas échéant, seront utilisées conformément à la politique de données utilisateur du Chrome Web Store, y compris les exigences d'utilisation limitée.

Vos droits

Selon votre localisation, y compris l'Espace économique européen, vous pouvez avoir des droits d'accès, de rectification, de suppression, de limitation, d'opposition ou de portabilité des données personnelles. Les données de lecture et d'annotation restent dans votre navigateur. Pour une demande concernant les informations de commentaires, contactez le responsable via le formulaire de commentaires lié sur ce site.

Enfants

wowMD ne s'adresse pas aux enfants et ne collecte pas sciemment d'informations personnelles auprès d'enfants.

Modifications

Si les pratiques de données de wowMD évoluent, cette politique sera mise à jour avant la publication de ces modifications.
