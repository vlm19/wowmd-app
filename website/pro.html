Read

Read long Markdown without losing structure.

Open local .md or .markdown files, continue from the extension, then navigate with outline, folding, syntax-highlighted code, wide-table inner scroll, full-text search, themes, and adjustable font size.

Document outline

Navigate by heading structure. The outline tracks your scroll position.

Section folding

Collapse sections you have read and keep focus on the current passage.

Code and tables

Syntax highlighting, one-click copy, and inner scrolling for wide tables.

Search and themes

Find matches with count and prev/next controls. Read in light or dark at your chosen font size.

Annotate

Four review types, not just colors. Each one is a judgment.

Select text, choose a semantic type, add notes or a suggested replacement. Every mark is anchored to the passage, stored locally, and survives source changes when possible.

Clarify needed Disputed Important Confirmed

Floating selection toolbar

Pick a review type or add a note with an optional suggested replacement.

Notes panel filters

Filter by type, jump back to the passage, and keep the review organized.

Cross-version survival

Understanding Map

See where confusion, disputes, and important points cluster.

The Understanding Map shows density of the four review types per section, so you can decide what to handle first.

Deliver

Four outputs. Different audiences.

Share annotated reading with people, send reviewed Markdown to Obsidian, back up your annotations, or hand a precise work order to an AI or editor.

For people

HTML export

Self-contained single file preserving structure, outline, highlights, and notes. Offline-readable and opens in any browser.

For Obsidian

Reviewed Markdown

A new .md copy with Obsidian-readable review callouts, wowMD tags, and review properties. It does not edit the original or apply suggested replacements.

For backup

Backup JSON

Raw annotations for backup or re-import. Your data remains portable and under your control.

For AI

Ticket JSON

Document snapshot, bilingual type legend, per-annotation section context, notes, and suggested replacements.

"type": "dispute"
"headingPath": ["Architecture"]
"note": "This claim needs correction."

Prompt: revise the whole document per these tickets.

Reviewed copy

Save an Obsidian-ready Markdown copy without touching the source.

Save reviewed copy creates a new .md file with paragraph-level Obsidian callouts for your wowMD marks, plus review properties and tags. It keeps the original Markdown unchanged; it does not rewrite the document, apply suggested replacements, or call AI.
