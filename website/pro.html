Export

Export as HTML to share, as JSON — AI is your choice.

Two export formats. Share annotated reading with people. If you choose to involve AI, structured JSON is ready — but the decision and the pipe are yours to control.

  • HTML export — self-contained single file with document structure, table of contents, code syntax highlighting, and all your highlights and notes preserved. Opens in any browser. No app runtime, no tracking. Responsive layout, offline-readable.
  • JSON export — structured annotations if you choose to involve AI. Feed into cloud AI, local AI, or no AI at all. The data is yours. The choice is yours.
  • Live preview — check the export before downloading. Choose what to include: TOC, heading anchors, highlights, metadata. Source tab for technical users. Estimated file size.
