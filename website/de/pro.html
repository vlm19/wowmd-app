Lesen

Langes Markdown lesen, ohne die Struktur zu verlieren.

Öffnen Sie lokale .md- oder .markdown-Dateien, setzen Sie von der Erweiterung aus fort und navigieren Sie dann mit Gliederung, Faltung, syntaxhervorgehobenem Code, innerem Scrollen für breite Tabellen, Volltextsuche, Themes und einstellbarer Schriftgröße.

Dokumentengliederung

Navigieren Sie nach Überschriftenstruktur. Die Gliederung passt sich langen Abschnittstiteln an.

Abschnittsfaltung

Klappen Sie bereits gelesene Abschnitte ein und bleiben Sie beim aktuellen Abschnitt fokussiert.

Code und Tabellen

Syntaxhervorhebung, Ein-Klick-Kopieren und inneres Scrollen für breite Tabellen.

Suche und Themes

Finden Sie Treffer mit Zähler und Vor/Zurück-Steuerung. Lesen Sie in Hell oder Dunkel in Ihrer gewählten Schriftgröße.

Kommentieren

Vier Review-Typen, nicht nur Farben. Jeder ist eine Beurteilung.

Wählen Sie Text aus, wählen Sie einen semantischen Typ, fügen Sie Notizen oder einen Ersetzungsvorschlag hinzu. Jede Markierung ist am Abschnitt verankert, lokal gespeichert und übersteht Quelländerungen, wenn möglich.

Schwebende Auswahl-Werkzeugleiste

Wählen Sie einen Review-Typ oder fügen Sie eine Notiz mit optionalem Ersetzungsvorschlag hinzu.

Filter im Notizen-Panel

Filtern Sie nach Typ, springen Sie zurück zum Abschnitt und halten Sie die Review organisiert.

Versionsübergreifender Erhalt

Wenn sich die Quelle ändert, verankern sich Kommentare automatisch neu; verwaiste Markierungen können mit Suchen wiederhergestellt werden.

Gesamt-Review-Karte

Verstehen Sie den Review-Fortschritt und finden Sie den nächsten Fokus.

Die Gesamt-Review-Karte verbindet Abschnittsabdeckung, Review-Sicherheit, Risikofokus und typisierte Anmerkungen, damit Sie gezielt Bereiche mit Handlungsbedarf stärken.

Ausliefern

Vier Ausgaben. Unterschiedliche Zielgruppen.

Teilen Sie kommentierte Lektüre mit Menschen, senden Sie geprüftes Markdown an Obsidian, sichern Sie Ihre Kommentare oder übergeben Sie einen präzisen Arbeitsauftrag an eine KI oder einen Redakteur.

Für Menschen

HTML-Export

Eigenständige Einzeldatei, die Struktur, Gliederung, Markierungen und Notizen bewahrt. Offline lesbar und in jedem Browser zu öffnen.

Für Obsidian

Geprüftes Markdown

Eine neue .md-Kopie mit Obsidian-lesbaren Review-Callouts, wowMD-Tags und Review-Properties. Sie bearbeitet das Original nicht und wendet keine Ersetzungsvorschläge an.

Für Backup

Backup JSON

Rohe Kommentardaten für Backup oder erneuten Import. Ihre Daten bleiben portabel und unter Ihrer Kontrolle.

Für KI

Ticket JSON

Dokument-Snapshot, zweisprachige Typenlegende, Abschnittskontext pro Kommentar, Notizen und Ersetzungsvorschläge.

"type": "dispute"
"headingPath": ["Architektur"]
"note": "Diese Aussage muss korrigiert werden."

Prompt: Überarbeiten Sie das gesamte Dokument gemäß diesen Tickets.

Geprüfte Kopie

Speichern Sie eine Obsidian-taugliche Markdown-Kopie, ohne die Quelle zu berühren.

Geprüfte Kopie speichern erstellt eine neue .md-Datei mit absatzbezogenen Obsidian-Callouts für Ihre wowMD-Markierungen sowie Review-Properties und Tags. Das ursprüngliche Markdown bleibt unverändert; es schreibt das Dokument nicht um, wendet keine Ersetzungsvorschläge an und ruft keine KI auf.
