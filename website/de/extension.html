Funktionen

Alles mit einem Ziel: besser lesen.

Gliederung zuerst

Sieh die Struktur, bevor du in den Text einsteigst.

Abschnitte einklappen

Große H2-Abschnitte lassen sich einzeln einklappen, wenn ein Dokument lang wird.

Codeblöcke

Klare Abstände und Hervorhebung sorgen dafür, dass Code lesbar bleibt.

Tabellen horizontal scrollen

Breite Tabellen lassen sich horizontal scrollen, ohne das Layout zu zerstören.

Anzeige nach Bedarf

Bei kurzen READMEs und einfachen Seiten bleibt wowMD unsichtbar.

Sauberes Rendering

Korrigiert häufige relative Bildpfade und bereinigt gerendertes Markdown.

Umfang

Fokussiert auf GitHub-Markdown — und klar bei den Grenzen.

Unterstützt

  • Öffentliche README-Seiten von GitHub-Repositories
  • Öffentliche .md-Dateiseiten auf GitHub
  • Öffentliche .markdown-Dateiseiten auf GitHub
  • Rechtes Panel und Vollbild-Reader

Noch nicht unterstützt

  • Private Repositories
  • Websites außerhalb von GitHub
  • Issues, Pull Requests oder Wiki-Seiten
  • KI-Zusammenfassungen, Übersetzung oder Cloud-Sync

Datenschutz

Ein Reader sollte keine unnötigen Daten brauchen.

Keine Erfassung personenbezogener Daten.

Keine Dokument-Uploads an Drittanbieter.

Keine KI-Zusammenfassungen, Cloud-Analyse oder Remote-Konfiguration.

Kein Zugriff auf Verlauf, Cookies, Kontoinformationen oder lokale Dateien.

Keine Raw-Markdown- oder GitHub-API-Anfrage, bevor du auf Better View klickst.

Mehr nötig?

Brauchst du lokale Dateien, Markierungen, Notizen oder Export?

wowMD Pro ergaenzt einen lokalen Markdown-Arbeitsbereich mit Annotationen und sauberem HTML-Export. Die kostenlose Erweiterung bleibt auf GitHub-Lesen fokussiert.
