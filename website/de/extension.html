Funktionen

Alles hier hat eine Aufgabe: besseres GitHub-Lesen.

GitHub Markdown öffnen

Funktioniert auf unterstützten öffentlichen Repository-README-Seiten und .md- oder .markdown-Dateiseiten.

Gliederungsnavigation

Nutzen Sie die Überschriftenstruktur, um lange Dokumente zu verstehen und darin zu springen.

Abschnittsfaltung

Klappen Sie große Abschnitte ein, wenn Sie nur den Teil brauchen, den Sie gerade lesen.

Code und Tabellen

Syntaxhervorhebung, lesbare Abstände und horizontales Tabellenscrolling halten technische Dokumente nutzbar.

Umfang

Fokussierter Umfang, keine verschwommenen Versprechen.

Unterstützt

  • Öffentliche GitHub-Repository-README-Seiten
  • Öffentliche GitHub-.md- und .markdown-Dateiseiten
  • Reader-Ansicht mit Gliederung, Faltung, Code und Tabellen

Nicht in der Erweiterung enthalten

  • Lokale Dateien
  • Kommentare, Verständniskarte, Versionen oder Export
  • Issues, Pull Requests, Wiki-Seiten oder Nicht-GitHub-Websites

Datenschutz

Ein Reader sollte Ihre Daten nicht brauchen.

Keine Erfassung personenbezogener Daten.

Keine Dokument-Uploads an Drittanbieter.

Keine KI-Zusammenfassungen, Cloud-Analysen oder Fernkonfiguration.

Brauchen Sie mehr?

Benötigen Sie lokale Dateien, typisierte Kommentare, die Verständniskarte oder Export?

wowMD Pro fügt den vollständigen lokalen Review-Workflow hinzu. Die Erweiterung bleibt auf das GitHub-Lesen fokussiert.
