最后更新：2026年5月25日

以下条款说明你可以如何使用 wowMD 网站、Chrome 扩展和 wowMD Pro webapp。

简要总结

负责任地使用 wowMD，保管好自己的文档和授权密钥，不要滥用服务。免费扩展和付费 webapp 均以专注的 Markdown 阅读工具提供。

接受

使用 wowMD 网站、扩展或 webapp 即表示你同意这些条款。如果你不同意，请勿使用 wowMD。

产品与范围

wowMD 包括一个用于公共 GitHub Markdown 页面的免费 Chrome 扩展，以及 wowMD Pro，一个用于本地 Markdown 阅读、类型化标注和导出的本地优先 webapp。两者在测试阶段均免费。功能可能随产品发展而改变。

授权与付费访问

wowMD Pro 在测试阶段免费。如果未来引入付费访问，将在相关的结账或产品页面上说明。不要分享、转售或滥用授权密钥或访问凭证。

定价与促销

wowMD Pro 在测试阶段免费。如果后续引入付费访问，具体价格、折扣、税费、货币和支付条款将在结账或相关购买页面显示。免费测试访问不保证产品将永久免费。

本地文件与用户内容

你对自己用 wowMD 打开或创建的 Markdown 文件、笔记、高亮和导出内容负责。该应用设计为在浏览器本地处理文档，但你应为重要文件和导出内容保留备份。

可接受的使用

不要将 wowMD 用于违法、侵犯他人权利、攻击或干扰服务、绕过技术限制、逆向工程付费访问控制或干扰其他用户。

第三方服务

wowMD 可能链接到第三方服务，如 Chrome Web Store、GitHub、支付提供商、反馈表单或视频托管平台。这些服务受其各自的条款和政策约束。

开源组件

wowMD 扩展可能随开源代码或依赖项一起分发。开源许可证继续适用于这些部分。这些条款不取消适用的开源许可证授予的权利。

无保证

wowMD 按现状和可用性提供。我们不保证每个 Markdown 文件、导出、浏览器、商店上架、阅读器或设备都能完美运行或无中断。

责任限制

在法律允许的最大范围内，wowMD 及其维护者不对因使用产品而产生的间接、附带、特殊、后果性或利润损失损害承担责任。

变更

当产品、授权、支付流程或法律要求发生变化时，我们可能更新这些条款。更新后的条款将发布在此页面并标注新的更新日期。

联系
