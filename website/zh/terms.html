条款与条件

最后更新：2026年6月6日

以下条款说明你可以如何使用 wowMD 网站、Chrome 扩展和 wowMD Pro webapp。

简要总结

负责任地使用 wowMD，保管好自己的文档，不要滥用服务。免费的 Chrome 扩展和 wowMD Pro webapp 以专注的 Markdown 阅读和审阅工具提供。两者在测试阶段均免费。

接受

使用 wowMD 网站、扩展或 webapp 即表示你同意这些条款。如果你不同意，请勿使用 wowMD。

产品与范围

wowMD 包括一个用于支持的公开 GitHub Markdown 页面的免费 Chrome 扩展，以及 wowMD Pro，一个本地优先的 webapp，用于本地 Markdown 阅读、四种审阅类型、总体审阅地图、跨版本重新锚定和四种导出格式（HTML、面向 Obsidian 的审阅版 Markdown、备份 JSON、工单 JSON）。两者在测试阶段均免费。功能可能随产品发展而改变。

授权与付费访问

wowMD Pro 在测试阶段免费。如果未来引入付费访问，将在相关的结账或产品页面上说明。不要分享、转售或滥用授权密钥或访问凭证。

定价与促销

wowMD Pro 在测试阶段免费。如果后续引入付费访问，具体价格、折扣、税费、货币和支付条款将在结账或相关购买页面显示。免费测试访问不保证产品将永久免费。

本地文件与用户内容

你对自己用 wowMD 打开或创建的 Markdown 文件、标注、备注、审阅副本和导出内容负责。应用在浏览器本地使用站点数据存储（IndexedDB）处理文档和标注。wowMD 不会修改你的源文件或应用建议替换。你应为重要文件、标注和导出内容保留备份。清理浏览器的站点数据、使用隐私浏览或浏览器存储回收可能导致数据丢失。

导出格式

wowMD Pro 提供四种导出格式，均在浏览器本地生成：(1) HTML——一个包含结构、高亮和备注的自包含文件，用于与人分享标注后的阅读成果；(2) 审阅版 Markdown——一个新的 .md 副本，包含 Obsidian 可读的审阅 callout、标签和属性，不修改原文件；(3) 备份 JSON——原始标注数据，用于备份或重新导入，完全可移植且由你掌控；(4) 工单 JSON——文档快照、类型对照表、章节上下文、备注和建议替换打包为 AI 辅助修订的工作指令。下载或分享导出文件后，其责任由你承担。

数据存储与丢失风险

wowMD Pro 将标注、文档指纹、导入文档副本、版本历史和偏好设置存储在浏览器的站点数据（IndexedDB）中。这些数据仅在本地浏览器中，不会跨设备同步或备份到服务器。清理浏览器的站点数据、切换到其他浏览器或配置文件、使用隐私/无痕窗口，或浏览器存储压力回收可能会永久删除你的标注和版本历史。请定期导出备份 JSON 以保护你的工作成果。

测试阶段

wowMD Pro 在测试阶段免费提供。测试阶段可能包含未完成的功能、未经通知的变更，以及版本之间数据不兼容的可能性。免费测试访问不保证产品将永久免费、功能将保留，或测试阶段的数据将与测试后的版本兼容。我们建议定期导出备份 JSON 副本。

Acceptable use

不要将 wowMD 用于违法、侵犯他人权利、攻击或干扰服务、绕过技术限制、逆向工程付费访问控制或干扰其他用户。

开源组件
