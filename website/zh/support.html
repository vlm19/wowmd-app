类型化审阅：四种判断，不只是颜色

当你在 wowMD 中标记文字时，你记录的是一个带有隐含动作的判断。这些类型驱动着笔记面板、理解地图和工单 JSON 的图例。

需澄清解释或澄清这一点，不改变其实质。
存疑审查这一说法；可能不正确，可能需要修正。
重要保留并强调这一关键点。
已确认已审阅且正确；无需操作。

跨版本存活

当源文档变化时，wowMD 会尝试用选中的引用文字和上下文将你的标注重新锚定到同一段落。如果某段文字确实消失，标注会变成孤儿状态，可通过 Find 手动恢复。

重新锚定是非破坏性的。wowMD 重新计算标注位置；它不会写回源文件。

工单 JSON：你的判断变成 AI 工作指令

工单打包了文档快照、双语类型对照表、章节上下文、选中引文、备注和建议替换。它与备份 JSON 不同——备份 JSON 只存储原始标注数据用于备份和重新导入。

  1. 点击应用中的
  2. 打开你选择的 AI 工具。
  3. 粘贴下面的提示词，然后粘贴工单内容。
你是一位严谨的编辑。我会给你一份 JSON 工单，其中包含我对 Markdown 文档的标注。
请按每条标注的类型处理，并输出完整修订后的文档。
- clarify: 解释或澄清，不改变实质
- dispute: 审查，若不正确则修正并说明原因
- important: 保留并强调
- confirmed: 保持不变
以 document.markdownSnapshot 为基础。用 headingPath、quote、prefix 和 suffix 定位每条标注。如提供了 suggestedReplacement，优先采用。
