Chrome 扩展

GitHub Markdown，更轻松地阅读。

该扩展在受支持的 GitHub Markdown 页面上提供更舒适的阅读器，包含大纲、折叠、代码渲染和可滚动表格。它有意限定在「打开和阅读」范围。

添加至 Chrome 需要标注功能？
GitHub Markdown 仅限打开和阅读 不上传文档

演示

看一篇冗长的 README 如何变成专注的阅读体验。

github.com/openclaw/openclaw

功能

一切都只为更好地阅读 GitHub 文档。

打开 GitHub Markdown

适用于受支持的公开仓库 README 页面以及 .md 或 .markdown 文件页面。

大纲导航

通过标题结构理解和跳转长篇文档。

章节折叠

折叠已读大段内容，只关注当前正在阅读的部分。

代码与表格

语法高亮、清晰间距和横向表格滚动，让技术文档保持可读。

范围

聚焦的范围，不模糊的承诺。

支持

  • 公开 GitHub 仓库 README 页面
  • 公开 GitHub .md 和 .markdown 文件页面
  • 带大纲、折叠、代码和表格的阅读器视图

扩展不包含

  • 本地文件
  • 标注、理解地图、版本或导出
  • Issues、Pull Requests、Wiki 页面或非 GitHub 网站

隐私

一个阅读器不应该索取你的数据。

不收集个人信息。

不将文档上传至第三方服务。

不含 AI 摘要、云端分析或远程配置。
