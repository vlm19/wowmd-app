再冗长的 MD 文档，也能轻松细读。

wowMD 是一款轻量 Chrome 扩展，轻松把冗长复杂的 GitHub Markdown 页面变成带目录、章节折叠和清爽渲染的结构化文档，并且只在真正需要时出现，只为提升你的阅读体验。

功能

所有的功能，都只为提升你的阅读体验。

目录优先

先看到文档结构，再进入完整正文。

章节折叠

文档变长时，可独立折叠大型 H2 章节。

代码渲染

用清晰间距和高亮保持代码块可读。

表格滚动

宽表格横向滚动，不破坏阅读布局。

智能出现

短 README 和简单页面保持安静，不打扰。

清爽渲染

修复常见相对图片路径，并清理渲染后的 Markdown。

边界

有边界的工具才是一个专注的工具。

已支持

  • 公开 GitHub 仓库 README 页面
  • 公开 GitHub .md 文件页面
  • 公开 GitHub .markdown 文件页面
  • 右侧面板和全屏阅读器

暂不支持

  • 私有仓库
  • 非 GitHub 网站
  • Issue、Pull Request 或 Wiki 页面
  • AI 总结、翻译或云同步

隐私保护

一个保护隐私的工具，才可能是一个好工具。

不收集个人信息。

不把文档上传到第三方服务。

不做 AI 总结、云分析或远程配置。

不读取浏览历史、Cookie、账号信息或本地文件。

点击 Better view 前，不请求 Raw Markdown 或 GitHub API。

需要更多？

需要本地文件、高亮、笔记或导出？

wowMD Pro 提供本地 Markdown 工作区，支持标注以及干净的 HTML 或 EPUB 导出。免费插件继续专注 GitHub 阅读。
