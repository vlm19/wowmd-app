隐私政策

隐私政策

最后更新：2026 年 5 月 18 日

wowMD 是一款本地优先的 Chrome 扩展，用于更舒适地阅读公开 GitHub Markdown 页面。

简明摘要

wowMD 不收集个人信息，不上传文档，不出售数据，也不追踪浏览历史。

数据控制方

如有与 wowMD 相关的隐私问题，可以通过本站页脚中的反馈表单联系维护者。

我们处理的数据

只有当你点击 Better View 时，扩展才会在浏览器本地读取页面内容。它不会收集账号数据、Cookie、浏览历史、本地文件或私有仓库内容。

处理目的与法律依据

数据处理仅限于提供你主动请求的阅读功能，例如目录导航、章节折叠、代码渲染和表格布局。在 GDPR 适用的情况下，其依据是提供你请求的服务，以及运营隐私友好型浏览器工具的合法利益。

存储与保留

wowMD 不为你的阅读活动维护远程数据库。临时处理发生在浏览器会话中，不会发送到 wowMD 服务器。

共享与第三方

wowMD 不出售或共享阅读数据。如果你通过 Google Form 提交反馈，你主动填写的信息会由 Google Forms 处理，可能包括表单回复和相关 Google 元数据。

Chrome Web Store 与 Limited Use

wowMD 仅为已披露的阅读功能使用浏览器权限。如未来接收任何来自 Google API 的信息，也会遵循 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

你的权利

根据你所在地区，包括欧洲经济区，你可能拥有访问、更正、删除、限制处理、反对处理或数据可携带等权利。由于 wowMD 不在服务器保存阅读数据，大多数请求会以说明实际收集与未收集的数据来回应。

儿童

wowMD 并非面向儿童，也不会有意收集儿童的个人信息。

政策变更

如果 wowMD 的数据处理方式发生变化，我们会在发布相关变更前更新本政策。
