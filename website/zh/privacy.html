隐私政策

隐私政策

最后更新：2026年5月18日

wowMD 被设计为一个本地优先的 Chrome 扩展，用于阅读公开的 GitHub Markdown 页面。

简要总结

wowMD 不收集个人信息，不上传文档，不出售数据，不追踪浏览历史。

控制者

关于 wowMD 的隐私问题，请通过本网站链接的反馈表单联系维护者。

我们处理的数据

扩展仅在你选择 Better View 时在浏览器本地读取页面内容。它不收集账户数据、Cookie、浏览历史、本地文件或私有仓库内容。

目的与法律依据

处理仅限于提供你所请求的阅读功能，如大纲导航、章节折叠、代码渲染和表格布局。在 GDPR 适用的情况下，此处理基于提供你所请求的服务以及运营一个保护隐私的浏览器工具的合法利益。

存储与保留

wowMD 不维护用于你的阅读活动的远程数据库。任何临时处理都在浏览器会话中发生，不会发送到 wowMD 服务器。

分享与第三方

wowMD 不会出售或分享阅读数据。如果你通过网站提交反馈，你选择提供的信息（如你的留言、功能偏好和可选邮箱地址）仅用于阅读反馈和跟进所请求的功能。

Chrome Web Store 和限制使用

wowMD 仅在提供所披露的阅读功能时才使用浏览器权限。从 Google API 获取的信息（如有）将根据 Chrome Web Store 用户数据政策（包括限制使用要求）使用。

你的权利

根据你所在的位置（包括欧洲经济区），你可能有权访问、更正、删除、限制、反对或迁移个人数据。由于 wowMD 不在服务器上存储阅读数据，大多数请求可以通过解释收集了什么、未收集什么来回答。

儿童

wowMD 不面向儿童，不会故意收集儿童的个人信息。

变更

如果 wowMD 改变其数据实践，本政策将在这些变更发布之前更新。
