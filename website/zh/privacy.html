隐私政策

隐私政策

最后更新：2026年6月6日

wowMD 包括一个本地优先的 Chrome 扩展（用于阅读公开 GitHub Markdown 页面）和 wowMD Pro（一个本地优先的 webapp，用于审阅、标注和导出 Markdown 文件）。

简要总结

wowMD 不收集个人信息，不上传文档或标注，不出售数据，不追踪浏览历史。所有导出均由你主动发起并在浏览器本地生成。

控制者

关于 wowMD 的隐私问题，请通过本网站链接的反馈表单联系维护者。

我们处理的数据

扩展仅在你选择 Better View 时在浏览器本地读取页面内容。wowMD Pro 读取你打开的本地 .md 文件，并存储你创建的标注、备注和建议替换。两个产品均不收集账户数据、Cookie、浏览历史或私有仓库内容。

目的与法律依据

扩展的处理仅限于你所请求的阅读功能：大纲导航、章节折叠、代码渲染和表格布局。Pro 的处理仅限于你所使用的审阅功能：结构化阅读、四种审阅类型、总体审阅地图、跨版本重新锚定以及你选择的导出格式。在 GDPR 适用的情况下，此处理基于提供你所请求的服务以及运营一个保护隐私的浏览器工具的合法利益。

存储与保留

wowMD 不维护用于你的阅读或审阅活动的远程数据库。扩展在浏览器会话中临时处理页面。wowMD Pro 将你的标注、导入的文档指纹、版本历史和设置本地存储在浏览器的站点数据（IndexedDB）中。这些数据永远不会发送到 wowMD 服务器。

分享与第三方

wowMD 不会出售或分享阅读或标注数据。所有导出均在你发起时在浏览器本地生成——生成的文件归你处置。如果你通过网站提交反馈，你选择提供的信息（如你的留言、功能偏好和可选邮箱地址）仅用于阅读反馈和跟进所请求的功能。

wowMD Pro 本地存储的数据

wowMD Pro 将以下数据存储在浏览器的站点数据（IndexedDB）中，绝不会发送到远程服务器：你创建的标注（类型、备注、建议替换、上下文）、用于跨版本重新锚定的文档指纹、用于审阅的导入文档副本、版本历史，以及你的偏好设置（主题、字号、布局）。这些数据保留在你的浏览器中，除非你选择导出。

Pro 导出与你的数据

所有导出均在你发起时在浏览器本地生成。HTML 导出包含渲染后的 Markdown 及可见的高亮和备注。审阅版 Markdown 将你的标注作为 Obsidian callout 包含在新的 .md 文件中。备份 JSON 包含你的原始标注数据，用于备份或重新导入。工单 JSON 包含完整的文档快照、你的标注和章节上下文——在与 AI 或第三方分享之前，请审查此内容。

Chrome Web Store 和限制使用

wowMD 仅在提供所披露的阅读功能时才使用浏览器权限。从 Google API 获取的信息（如有）将根据 Chrome Web Store 用户数据政策（包括限制使用要求）使用。

你的权利

根据你所在的位置（包括欧洲经济区），你可能有权访问、更正、删除、限制、反对或迁移个人数据。由于 wowMD 不在服务器上存储阅读或标注数据，大多数请求可以通过解释收集了什么、未收集什么来回答。

儿童

wowMD 不面向儿童，不会故意收集儿童的个人信息。

变更

如果 wowMD 改变其数据实践，本政策将在这些变更发布之前更新。
