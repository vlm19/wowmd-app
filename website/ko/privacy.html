개인정보 처리방침

최종 업데이트: 2026년 5월 18일

wowMD는 공개 GitHub Markdown 페이지를 읽기 위한 로컬 우선 Chrome 확장 프로그램으로 설계되었습니다.

간단 요약

wowMD는 개인정보를 수집하지 않으며, 문서를 업로드하지 않고, 데이터를 판매하지 않으며, 브라우징 기록을 추적하지 않습니다.

관리자

wowMD에 관한 개인정보 문의는 이 웹사이트에 링크된 피드백 양식을 통해 관리자에게 연락하세요.

처리하는 데이터

확장 프로그램은 Better View를 선택할 때만 페이지 콘텐츠를 브라우저 내에서 로컬로 읽습니다. 계정 데이터, 쿠키, 브라우징 기록, 로컬 파일, 비공개 저장소 콘텐츠를 수집하지 않습니다.

목적 및 법적 근거

처리는 목차 탐색, 섹션 접기, 코드 렌더링, 표 레이아웃 등 사용자가 요청한 읽기 기능을 제공하는 것으로 제한됩니다. GDPR이 적용되는 경우, 이는 요청된 서비스 제공 및 개인정보 보호 브라우저 도구 운영의 정당한 이익에 기반합니다.

저장 및 보존

wowMD는 읽기 활동에 대한 원격 데이터베이스를 유지하지 않습니다. 모든 임시 처리는 브라우저 세션 내에서 이루어지며 wowMD 서버로 전송되지 않습니다.

공유 및 제3자

wowMD는 읽기 데이터를 판매하거나 공유하지 않습니다. 웹사이트를 통해 피드백을 제출하는 경우, 메시지, 기능 선호도, 선택적 이메일 주소 등 귀하가 제공하기로 선택한 정보는 피드백을 읽고 요청된 기능에 대한 후속 조치를 위해서만 사용됩니다.

Chrome Web Store 및 제한적 사용

wowMD는 공개된 읽기 기능을 제공하기 위해서만 브라우저 권한을 사용합니다. Google API에서 수신한 정보가 있는 경우, 제한적 사용 요구사항을 포함한 Chrome Web Store 사용자 데이터 정책에 따라 사용됩니다.

귀하의 권리

유럽 경제 지역을 포함한 귀하의 위치에 따라, 개인 데이터에 대한 접근, 정정, 삭제, 제한, 이의 제기, 이전 권리가 있을 수 있습니다. wowMD는 서버에 읽기 데이터를 저장하지 않으므로, 대부분의 요청은 수집 여부를 설명하는 것으로 답변할 수 있습니다.

아동

wowMD는 아동을 대상으로 하지 않으며, 고의로 아동으로부터 개인정보를 수집하지 않습니다.

변경 사항

wowMD의 데이터 관행이 변경되는 경우, 변경 사항이 배포되기 전에 본 방침이 업데이트됩니다.
