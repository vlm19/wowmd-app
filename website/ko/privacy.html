개인정보 처리방침

최종 업데이트: 2026년 5월 18일

wowMD는 공개 GitHub Markdown 페이지를 더 편하게 읽기 위한 로컬 우선 Chrome 확장 프로그램입니다.

간단 요약

wowMD는 개인 정보를 수집하지 않고, 문서를 업로드하지 않으며, 데이터를 판매하거나 브라우징 기록을 추적하지 않습니다.

관리 주체

wowMD 개인정보 관련 문의는 이 웹사이트의 피드백 양식을 통해 관리자에게 보낼 수 있습니다.

처리하는 데이터

확장 프로그램은 사용자가 Better View를 선택한 경우에만 브라우저 안에서 페이지 내용을 로컬로 읽습니다. 계정 데이터, 쿠키, 브라우징 기록, 로컬 파일, 비공개 저장소 내용은 수집하지 않습니다.

목적과 법적 근거

처리는 사용자가 요청한 목차 탐색, 섹션 접기, 코드 렌더링, 표 레이아웃 같은 읽기 기능을 제공하는 데 한정됩니다. GDPR이 적용되는 경우, 근거는 요청한 서비스 제공과 개인정보 보호 중심 브라우저 도구 운영에 대한 정당한 이익입니다.

저장과 보관

wowMD는 읽기 활동을 위한 원격 데이터베이스를 운영하지 않습니다. 임시 처리는 브라우저 세션 안에서 이루어지며 wowMD 서버로 전송되지 않습니다.

공유와 제3자

wowMD는 읽기 데이터를 판매하거나 공유하지 않습니다. Google Form으로 피드백을 제출하면 사용자가 제공한 정보는 Google Forms에서 처리되며, 응답 내용과 관련 Google 메타데이터가 포함될 수 있습니다.

Chrome Web Store 및 Limited Use

wowMD는 공개된 읽기 기능을 제공하기 위해서만 브라우저 권한을 사용합니다. Google API에서 정보를 받는 경우에도 Chrome Web Store User Data Policy와 Limited Use 요건을 따릅니다.

사용자의 권리

유럽경제지역을 포함한 거주 지역에 따라 접근, 정정, 삭제, 제한, 반대, 데이터 이동권이 있을 수 있습니다. wowMD는 읽기 데이터를 서버에 저장하지 않으므로 대부분의 요청은 무엇을 수집하고 수집하지 않는지 설명하는 방식으로 처리됩니다.

아동

wowMD는 아동을 대상으로 하지 않으며 아동의 개인정보를 고의로 수집하지 않습니다.

변경

wowMD의 데이터 처리 방식이 변경되면 해당 변경 사항을 배포하기 전에 이 정책을 업데이트합니다.
