개인정보 처리방침

최종 업데이트: 2026년 6월 6일

wowMD는 공개 GitHub Markdown 페이지를 읽기 위한 로컬 우선 Chrome 확장 프로그램과 Markdown 파일을 검토, 주석 달기, 내보내기 위한 로컬 우선 webapp인 wowMD Pro를 포함합니다.

간단 요약

wowMD는 Markdown 문서와 주석을 브라우저에 보관합니다. 웹사이트는 Google Analytics를 사용하며, 선택적으로 제출한 피드백은 wowMD로 전송됩니다. wowMD는 문서 또는 주석 데이터를 판매하지 않습니다.

관리자

wowMD에 관한 개인정보 문의는 이 웹사이트에 링크된 피드백 양식을 통해 관리자에게 연락하세요.

처리하는 데이터

확장 프로그램은 Better View를 선택할 때만 브라우저에서 로컬로 페이지 콘텐츠를 읽습니다. wowMD Pro는 사용자가 연 로컬 .md 파일을 읽고 주석을 로컬에 저장합니다. 두 제품 모두 Markdown 문서나 주석을 업로드하지 않습니다. 웹사이트는 Google Analytics를 사용하며 Google의 개인정보처리방침에 따라 페이지 URL, 브라우저 또는 기기 식별자 및 쿠키를 처리할 수 있습니다.

목적 및 법적 근거

확장 프로그램의 처리는 목차 탐색, 섹션 접기, 코드 렌더링, 표 레이아웃 등 요청한 읽기 기능 제공으로 제한됩니다. Pro의 처리는 구조화된 읽기, 4가지 주석 유형, 전체 리뷰 맵, 버전 간 재고정, 선택한 내보내기 형식 등 사용하는 검토 기능으로 제한됩니다. GDPR이 적용되는 경우, 이는 요청한 서비스 제공과 개인정보 보호 브라우저 도구 운영의 정당한 이익에 기반합니다.

저장 및 보존

wowMD는 읽기 또는 검토 활동을 위한 원격 데이터베이스를 유지하지 않습니다. 확장 프로그램은 브라우저 세션에서 일시적으로 페이지를 처리하고, wowMD Pro는 주석, 문서 지문, 버전 및 설정을 브라우저 사이트 데이터(IndexedDB)에 저장합니다. 피드백은 Cloudflare D1에 저장되며 제출한 메시지, 기능 선호도, 선택적 이메일 주소, 페이지 URL, 사용자 에이전트 및 IP 주소와 사용자 에이전트에서 파생된 해시를 포함합니다. 피드백은 관리자가 삭제할 때까지 보관됩니다.

공유 및 제3자

wowMD는 읽기 또는 주석 데이터를 판매하거나 공유하지 않습니다. 내보내기는 사용자가 시작할 때 로컬로 생성됩니다. Google Analytics는 Google이 제공하며 웹사이트 피드백은 Cloudflare가 처리하고 저장합니다. 피드백 정보는 피드백을 읽고 요청된 기능을 후속 조치하는 용도로만 사용됩니다.

wowMD Pro가 로컬에 저장하는 데이터

wowMD Pro는 다음 데이터를 브라우저의 사이트 데이터(IndexedDB)에 저장하며, 원격 서버로 전송하지 않습니다: 생성한 주석(유형, 메모, 대체 제안, 컨텍스트), 버전 간 재고정에 사용되는 문서 핑거프린트, 검토용 가져온 문서 사본, 버전 기록, 설정(테마, 글꼴 크기, 레이아웃). 이 데이터는 내보내기를 선택하지 않는 한 브라우저에 유지됩니다.

Pro 내보내기와 데이터

모든 내보내기는 사용자가 시작할 때 브라우저 내에서 로컬로 생성됩니다. HTML 내보내기에는 하이라이트와 메모가 표시된 렌더링된 Markdown이 포함됩니다. 검토 Markdown에는 Obsidian 콜아웃으로 주석이 새 .md 파일에 포함됩니다. 백업 JSON에는 백업 또는 재가져오기용 원시 주석 데이터가 포함됩니다. 티켓 JSON에는 전체 문서 스냅샷, 주석, 섹션 컨텍스트가 포함됩니다. AI나 제3자와 공유하기 전에 이 내용을 검토하세요.

Chrome Web Store 및 제한적 사용

wowMD는 공개된 읽기 기능을 제공하기 위해서만 브라우저 권한을 사용합니다. Google API에서 수신한 정보가 있는 경우, 제한적 사용 요구사항을 포함한 Chrome Web Store 사용자 데이터 정책에 따라 사용됩니다.

귀하의 권리

유럽 경제 지역을 포함한 위치에 따라 개인 데이터에 대한 접근, 정정, 삭제, 제한, 이의 제기 또는 이전 권리가 있을 수 있습니다. 읽기와 주석 데이터는 브라우저에 남습니다. 피드백 정보에 관한 요청은 이 웹사이트에 연결된 피드백 양식으로 관리자에게 연락해 주세요.

아동

wowMD는 아동을 대상으로 하지 않으며, 고의로 아동으로부터 개인정보를 수집하지 않습니다.

변경 사항

wowMD의 데이터 관행이 변경되는 경우, 변경 사항이 배포되기 전에 본 방침이 업데이트됩니다.
