기능

목차 먼저

섹션 접기

코드 표시

깔끔한 간격과 하이라이트로 코드 블록을 읽기 좋게 유지합니다.

표 가로 스크롤

넓은 표는 가로로 스크롤되어 리더 레이아웃을 깨지 않습니다.

필요할 때만 표시

짧은 README와 단순한 페이지에서는 나타나지 않아 방해하지 않습니다.

깔끔한 렌더링

자주 쓰이는 상대 이미지 경로를 보정하고, 렌더링된 Markdown을 안전하게 정리합니다.

지원 범위

GitHub Markdown에 집중하고, 지원 범위를 분명히 합니다.

지원됨

  • 공개 GitHub 저장소 README 페이지
  • 공개 GitHub .md 파일 페이지
  • 공개 GitHub .markdown 파일 페이지
  • 오른쪽 패널과 전체 화면 리더

아직 지원하지 않음

  • 비공개 저장소
  • GitHub 외 웹사이트
  • Issue, Pull Request, Wiki 페이지
  • AI 요약, 번역, 클라우드 동기화

개인정보 보호

읽기 도구가 불필요한 데이터를 요구할 이유는 없습니다.

개인정보를 수집하지 않습니다.

문서를 타사 서비스로 업로드하지 않습니다.

AI 요약, 클라우드 분석, 원격 설정을 사용하지 않습니다.

방문 기록, 쿠키, 계정 정보, 로컬 파일에 접근하지 않습니다.

Better View를 클릭하기 전에는 Raw Markdown이나 GitHub API를 요청하지 않습니다.
