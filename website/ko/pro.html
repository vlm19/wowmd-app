Markdown을 검토하세요. 원본은 건드리지 않습니다.

모든 Markdown을 구조적으로 읽고 네 가지 검토 유형으로 판단을 기록한 뒤 사람, Obsidian, 백업 또는 AI 지원 수정에 맞는 결과물을 전달하세요. 로컬 우선이며 비파괴적입니다.

읽기

구조를 잃지 않고 긴 Markdown을 읽으세요.

로컬 .md 또는 .markdown 파일을 열거나 확장 프로그램에서 이어서 작업하세요. 목차, 접기, 구문 강조 코드, 넓은 표 내부 스크롤, 전체 텍스트 검색, 테마, 조절 가능한 글꼴 크기로 탐색할 수 있습니다.

문서 목차

제목 구조로 이동하며 긴 섹션 제목에 맞춰 목차 너비가 자동 조정됩니다.

섹션 접기

읽은 섹션을 접고 현재 읽고 있는 부분에 집중하세요.

코드 및 표

구문 강조, 원클릭 복사, 넓은 표를 위한 내부 스크롤.

검색 및 테마

일치 항목 수와 이전/다음 컨트롤로 검색하세요. 선택한 글꼴 크기로 라이트 또는 다크 모드에서 읽을 수 있습니다.

주석

단순한 색상이 아닌 네 가지 리뷰 유형. 각각은 하나의 판단입니다.

텍스트를 선택하고 의미 있는 유형을 고른 뒤 메모나 대체 제안을 추가하세요. 모든 마크는 해당 문단에 고정되고 로컬에 저장되며, 가능한 경우 원본 변경 후에도 유지됩니다.

확인 필요 의문 있음 중요 확인 완료

플로팅 선택 도구 모음

리뷰 유형을 선택하거나 선택적 대체 제안과 함께 메모를 추가하세요.

메모 패널 필터

유형별로 필터링하고, 해당 문단으로 이동하며, 리뷰를 체계적으로 정리하세요.

버전 간 유지

원본이 변경되면 주석이 자동으로 재고정되며, 분리된 마크는 찾기 기능으로 복구할 수 있습니다.

전체 리뷰 맵

전체 검토 진행 상황을 파악하고 다음에 집중할 부분을 찾으세요.

전체 리뷰 맵은 섹션 커버리지, 검토 신뢰도, 위험 초점, 유형별 주석을 결합해 주의가 필요한 부분을 강화하도록 돕습니다.

전달

네 가지 출력물. 각기 다른 대상.

사람에게 주석이 담긴 읽기 결과를 공유하고, 검토 Markdown을 Obsidian으로 보내고, 주석을 백업하거나, AI나 편집자에게 정확한 작업 지시를 전달하세요.

사람에게

HTML 내보내기

구조, 목차, 하이라이트, 메모를 보존한 독립형 단일 파일입니다. 오프라인에서 읽을 수 있으며 모든 브라우저에서 열립니다.

Obsidian용

검토 Markdown

Obsidian에서 읽을 수 있는 리뷰 callout, wowMD 태그, 리뷰 properties를 담은 새 .md 사본입니다. 원본을 수정하지 않고 제안된 대체 문구도 적용하지 않습니다.

Obsidian
백업용

백업 JSON

백업 또는 재가져오기를 위한 원시 주석 데이터. 데이터는 이식 가능하며 여러분의 통제 하에 있습니다.

AI에게

티켓 JSON

문서 스냅샷, 이중 언어 유형 범례, 주석별 섹션 컨텍스트, 메모, 대체 제안.

"type": "dispute"
"headingPath": ["아키텍처"]
"note": "이 주장은 수정이 필요합니다."

프롬프트: 이 티켓에 따라 전체 문서를 수정하세요.

검토 사본

원본을 건드리지 않고 Obsidian-ready Markdown 사본을 저장하세요.

검토 사본 저장은 wowMD 마크를 문단 단위 Obsidian callout으로 변환하고 리뷰 properties와 태그를 추가한 새 .md 파일을 만듭니다. 원본 Markdown은 그대로 유지됩니다. 문서를 다시 쓰거나, 제안된 대체 문구를 적용하거나, AI를 호출하지 않습니다.
