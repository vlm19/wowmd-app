본 약관은 wowMD 웹사이트, Chrome 확장 프로그램, wowMD Pro 웹앱의 이용 방법을 설명합니다.

간단 요약

wowMD를 책임감 있게 사용하고, 본인의 문서를 안전하게 보관하며, 서비스를 오용하지 마세요. 무료 Chrome 확장 프로그램과 wowMD Pro webapp은 집중적인 Markdown 읽기 및 검토 도구로 제공됩니다. 두 제품 모두 베타 기간 동안 무료입니다.

동의

wowMD 웹사이트, 확장 프로그램, 웹앱을 이용함으로써 본 약관에 동의하는 것입니다. 동의하지 않는 경우 wowMD를 사용하지 마세요.

제품 및 범위

wowMD는 지원되는 공개 GitHub Markdown 페이지용 무료 Chrome 확장 프로그램과 로컬 Markdown 읽기, 4가지 주석 유형, 전체 리뷰 맵, 버전 간 재고정, 4가지 내보내기 형식(HTML, Obsidian용 검토 Markdown, 백업 JSON, 티켓 JSON)을 갖춘 로컬 우선 webapp인 wowMD Pro를 포함합니다. 두 제품 모두 베타 기간 동안 무료입니다. 제품 발전에 따라 기능이 변경될 수 있습니다.

라이선스 및 유료 접근

wowMD Pro는 베타 기간 동안 무료입니다. 향후 유료 접근이 도입될 경우, 관련 결제 또는 제품 페이지에 설명됩니다. 라이선스 키나 접근 자격 증명을 공유, 재판매, 남용하지 마세요.

가격 및 프로모션

wowMD Pro는 베타 기간 동안 무료입니다. 추후 유료 접근이 도입될 경우, 정확한 가격, 할인, 세금, 통화, 결제 조건이 결제 시점이나 관련 구매 페이지에 표시됩니다. 베타 기간 무료 이용이 제품이 영구히 무료임을 보장하지는 않습니다.

로컬 파일 및 사용자 콘텐츠

wowMD로 열거나 생성한 Markdown 파일, 주석, 메모, 검토 사본, 내보내기에 대한 책임은 사용자에게 있습니다. 앱은 브라우저의 사이트 데이터 저장소(IndexedDB)를 사용하여 문서와 주석을 로컬로 처리합니다. wowMD는 소스 파일을 수정하거나 제안된 대체 문구를 적용하지 않습니다. 중요한 파일, 주석, 내보낸 콘텐츠의 백업을 유지해야 합니다. 브라우저의 사이트 데이터 삭제, 개인정보 보호 브라우징 사용, 브라우저 저장소 압박으로 인한 삭제는 데이터 손실을 초래할 수 있습니다.

내보내기 형식

wowMD Pro는 4가지 내보내기 형식을 제공하며, 모두 브라우저 내에서 로컬로 생성됩니다: (1) HTML — 구조, 하이라이트, 메모가 포함된 독립형 파일로, 주석이 달린 읽기 결과를 사람과 공유하기 위한 것; (2) 검토 Markdown — Obsidian에서 읽을 수 있는 리뷰 콜아웃, 태그, 속성이 포함된 새 .md 사본으로, 원본 파일은 수정하지 않음; (3) 백업 JSON — 백업 또는 재가져오기용 원시 주석 데이터. 완전히 이식 가능하며 사용자의 통제 하에 있음; (4) 티켓 JSON — 문서 스냅샷, 유형 범례, 섹션 컨텍스트, 메모, 대체 제안을 AI 지원 개정을 위한 작업 지시로 패키징. 다운로드 또는 공유 후 내보내기의 책임은 사용자에게 있습니다.

데이터 저장 및 손실

wowMD Pro는 주석, 문서 핑거프린트, 가져온 문서 사본, 버전 기록, 설정을 브라우저의 사이트 데이터(IndexedDB)에 저장합니다. 이 데이터는 브라우저에 로컬로 존재하며, 기기 간 동기화되거나 서버에 백업되지 않습니다. 브라우저의 사이트 데이터 삭제, 다른 브라우저나 프로필로 전환, 개인정보/시크릿 창 사용, 브라우저 저장소 압박으로 인한 삭제는 주석과 버전 기록을 영구적으로 삭제할 수 있습니다. 작업을 보호하려면 정기적으로 백업 JSON을 내보내세요.

베타 기간

wowMD Pro는 베타 기간 동안 무료로 제공됩니다. 베타 액세스에는 불완전한 기능, 예고 없는 변경, 버전 간 데이터 비호환성 가능성이 포함될 수 있습니다. 무료 베타 액세스는 제품이 영구적으로 무료임을, 기능이 유지됨을, 또는 베타 기간 데이터가 베타 이후 릴리스와 호환됨을 보장하지 않습니다. 주석의 백업 JSON 사본을 정기적으로 내보내는 것을 권장합니다.

허용되는 사용

wowMD를 법률 위반, 타인의 권리 침해, 서비스 공격 또는 방해, 기술적 제한 우회, 유료 접근 제어 리버스 엔지니어링, 다른 사용자 방해에 사용하지 마세요.

제3자 서비스

wowMD는 Chrome Web Store, GitHub, 결제 제공업체, 피드백 양식, 비디오 호스트 등 제3자 서비스로 연결될 수 있습니다. 해당 서비스는 자체 약관과 정책의 적용을 받습니다.

오픈소스 구성 요소

wowMD 확장 프로그램은 오픈소스 코드 또는 의존성과 함께 배포될 수 있습니다. 오픈소스 라이선스는 해당 부분에 계속 적용됩니다. 본 약관은 적용 가능한 오픈소스 라이선스가 부여하는 권리를 제거하지 않습니다.

보증 없음

wowMD는 있는 그대로, 이용 가능한 대로 제공됩니다. 모든 Markdown 파일, 내보내기, 브라우저, 스토어 등록, 리더, 기기가 완벽하게 또는 중단 없이 작동한다고 약속하지 않습니다.

책임 제한

법이 허용하는 최대 범위 내에서, wowMD와 그 관리자는 제품 사용으로 인해 발생하는 간접적, 부수적, 특별, 결과적 또는 이익 손실 손해에 대해 책임을 지지 않습니다.

변경 사항

제품, 라이선스, 결제 흐름, 법적 요구사항이 변경될 때 본 약관을 업데이트할 수 있습니다. 업데이트된 약관은 새로운 업데이트 날짜와 함께 이 페이지에 게시됩니다.

문의

본 약관에 관한 문의는 이 웹사이트에 링크된 피드백 양식을 통해 관리자에게 연락하세요.
