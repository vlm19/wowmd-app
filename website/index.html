Features

Everything here has one job: better reading.

Outline first

See the document structure before jumping into the full text.

Section folding

Collapse large H2 sections independently when a document gets long.

Code display

Keep code blocks readable with clean spacing and highlighting.

Horizontal table scrolling

Wide tables scroll sideways instead of breaking the reader layout.

Appears when useful

Stays out of the way on short READMEs and simple pages.

Clean rendering

Fixes common relative image paths and safely sanitizes rendered Markdown.

Scope

Focused on GitHub Markdown, clear about the rest.

Supported

  • Public GitHub repository README pages
  • Public GitHub .md file pages
  • Public GitHub .markdown file pages
  • Right-side panel and full-screen reader

Not supported yet

  • Private repositories
  • Websites outside GitHub
  • Issues, pull requests, or wiki pages
  • AI summaries, translation, or cloud sync

Privacy

A reader should not need your data.

No personal information collection.

No document uploads to third-party services.

No AI summaries, cloud analysis, or remote configuration.

No access to browsing history, cookies, account information, or local files.

No Raw Markdown or GitHub API request until you click Better View.
