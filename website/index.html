Open Drag, drop, or import
Open .md files directly in your browser. Drag-and-drop, file picker, or continue from the Chrome extension. The document stays in your browser — nothing is uploaded, nothing leaves your machine.

Read Outline / Search / Fold
Navigate by document outline. Collapse sections you've skimmed. Search for terms. Read code blocks with syntax highlighting and tables without broken layout. Light and dark themes.
↓
Judge & annotate Highlight / Note / Persist
Select text. A toolbar appears. Pick one of six colors for quick highlights. Add a note when you have a thought. Notes stay linked to the passage. All stored locally. This is what turns reading a file into processing knowledge.
HTML → ← JSON
HTML export For people
Self-contained HTML file with your highlights and notes preserved. Document structure, table of contents, code syntax highlighting, responsive layout. Opens in any browser. No app runtime. Share with your team.
JSON export For AI
Structured annotations exported as JSON. Feed them into an AI tool if you choose — or don't. Use cloud AI, local AI, or no AI at all. The data is yours. The decision is yours.

Nothing is uploaded. Everything stays on your device.
