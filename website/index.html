Frequently asked questions

wowMD is a local-first review layer for long Markdown. You read with structure, judge passages with four review types, keep annotations anchored as files change, and export the result for people, Obsidian, backup, or AI — without modifying the original file.

The extension turns public GitHub Markdown pages into a structured reader with outline, folding, code, and table support. wowMD Pro is the full review workspace for local Markdown files: typed annotations, notes, cross-version anchoring, an Overall Review Map, and four export formats.

Four outputs for different readers: offline HTML for people, reviewed Markdown for Obsidian, Backup JSON for annotation backup and re-import, and Ticket JSON as a structured work order for an AI tool or editor.

wowMD does not run AI analysis on your documents. AI is optional and external: you can export a Ticket JSON and decide yourself whether to hand it to an AI tool for revision.
