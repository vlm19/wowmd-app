Features

Every feature exists to improve your reading experience.

Outline first

Open with document structure before jumping into the full text.

Section folding

Collapse large H2 sections independently when a document gets long.

Code rendering

Keep code blocks readable with clean spacing and highlighting.

Table scrolling

Wide tables scroll sideways instead of breaking the reader layout.

Smart appearance

Stay out of the way on short README files and simple pages.

Clean rendering

Fix common relative image paths and sanitize rendered Markdown.

Boundary

A tool with boundaries is a focused tool.

Supported

  • Public GitHub repository README pages
  • Public GitHub .md file pages
  • Public GitHub .markdown file pages
  • Right-side panel and full-screen reader

Not supported yet

  • Private repositories
  • Non-GitHub websites
  • Issues, pull requests, or wiki pages
  • AI summaries, translation, or cloud sync

Privacy protection

A tool that protects privacy can become a good tool.

No personal information collection.

No document upload to third-party services.

No AI summaries, cloud analysis, or remote configuration.

No browsing history, cookies, account information, or local file access.

No Raw Markdown or GitHub API request before you click Better view.
