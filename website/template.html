Features

Everything here has one job: better GitHub reading.

Open GitHub Markdown

Works on supported public repository README pages and .md or .markdown file pages.

Outline navigation

Use heading structure to understand and jump through long documents.

Section folding

Collapse large sections when you only need the part you are reading now.

Code and tables

Syntax highlighting, readable spacing, and horizontal table scrolling keep technical docs usable.

Scope

Focused scope, no blurred promises.

Supported

  • Public GitHub repository README pages
  • Public GitHub .md and .markdown file pages
  • Reader view with outline, folding, code, and tables

Not included in the extension

  • Local files
  • Annotations, Understanding Map, versions, or export
  • Issues, pull requests, wiki pages, or non-GitHub websites

Privacy

A reader should not need your data.

No personal information collection.

No document uploads to third-party services.

No AI summaries, cloud analysis, or remote configuration.
