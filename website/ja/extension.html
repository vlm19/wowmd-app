Chrome拡張機能

GitHub Markdownを、より読みやすく。

この拡張機能は、対応するGitHub Markdownページを、目次・折りたたみ・コード表示・スクロール可能な表を備えた、より落ち着いたリーダーで開きます。意図的に「開く・読む」だけに範囲を絞っています。

Chromeに追加 注釈が必要ですか？
GitHub Markdown 開く・読むのみ ドキュメントのアップロードなし

デモ

長いREADMEが集中リーダーになる様子を見る。

github.com/openclaw/openclaw

機能

すべてはGitHub読書をより良くするためだけに。

GitHub Markdownを開く

対応する公開リポジトリのREADMEページと.mdまたは.markdownファイルページで動作します。

目次ナビゲーション

見出し構造を使って長い文書を理解し、ジャンプします。

セクション折りたたみ

読んだ大きなセクションを折りたたみ、今読んでいる部分だけに集中します。

コードと表

シンタックスハイライト、読みやすい間隔、横スクロール表で技術文書を使いやすく。

範囲

焦点を絞った範囲、曖昧な約束なし。

対応

  • 公開GitHubリポジトリのREADMEページ
  • 公開GitHubの.mdおよび.markdownファイルページ
  • 目次・折りたたみ・コード・表を備えたリーダービュー

拡張機能に含まれないもの

  • ローカルファイル
  • 注釈・理解マップ・バージョン・エクスポート
  • Issue・プルリクエスト・Wikiページ・GitHub以外のサイト

プライバシー

リーダーにあなたのデータは必要ない。

個人情報の収集なし。

第三者サービスへのドキュメントアップロードなし。

AI要約・クラウド分析・リモート設定なし。

もっと必要ですか？

ローカルファイル・型付き注釈・理解マップ・エクスポートが必要ですか？

wowMD Proは完全なローカル優先レビューワークフローを追加します。拡張機能はGitHub読書に集中。
