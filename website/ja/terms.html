利用規約

最終更新日：2026年5月25日

この規約は、wowMD のウェブサイト、Chrome 拡張機能、wowMD Pro Web アプリの利用条件を説明します。

概要

wowMD を責任をもって使用し、自分の文書とライセンスキーを安全に管理し、サービスを悪用しないでください。無料拡張機能と有料 Web アプリは、Markdown を読むための集中したツールとして提供されます。

規約への同意

wowMD のウェブサイト、拡張機能、または Web アプリを使用することで、この規約に同意したものとみなされます。同意しない場合は wowMD を使用しないでください。

製品と範囲

wowMD には現在、対応する公開 GitHub Markdown ページ用の無料 Chrome 拡張機能と、ローカル Markdown の閲覧、ハイライト、メモ、HTML 書き出し、EPUB 書き出しのための有料ローカル優先 Web アプリ wowMD Pro が含まれます。機能は製品の発展に伴って変更される場合があります。

ライセンスと有料アクセス

wowMD Pro は一回払いの永久ライセンスとして販売される場合や、試用として提供される場合があります。別途書面による合意がない限り、ライセンスは個人利用のためのものです。ライセンスキーを共有、再販売、または悪用しないでください。

価格とプロモーション

wowMD Pro は、無料の早期アクセス、試用、早期購入、一回払いの永久ライセンス、プロモーション割引、またはその他の有料アクセスとして提供される場合があります。正確な価格、割引、税金、通貨、支払い条件は、チェックアウト画面または関連する購入ページに表示されます。価格とプロモーションは、製品段階、提供状況、ユーザー需要、または事業上の必要に応じて変更される場合があります。無料アクセス、テストアクセス、またはプロモーションアクセスは、製品が永久に無料であり続けることを保証するものではありません。

ローカルファイルとユーザーコンテンツ

wowMD で開いたり作成したりする Markdown ファイル、メモ、ハイライト、書き出し内容については利用者が責任を負います。アプリはブラウザー内でローカルに文書を処理するよう設計されていますが、重要なファイルと書き出し内容はバックアップしてください。

許容される利用

第三者サービス

wowMD は Chrome Web Store、GitHub、決済事業者、フィードバックフォーム、動画ホストなどの第三者サービスへリンクする場合があります。これらのサービスには、それぞれの規約とポリシーが適用されます。
