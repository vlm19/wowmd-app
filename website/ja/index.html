よくある質問

wowMD はローカルファーストの長文 Markdown レビューレイヤーです。構造化された読書、4 つのレビュータイプによる判断、ファイル変更をまたぐアンカー維持、そして人・Obsidian・バックアップ・AI へのエクスポート。元のファイルは一切変更しません。

はい、ベータ期間中は無料です。Chrome 拡張は無料で、wowMD Pro もベータ期間中は無料です。

いいえ。ローカルファイルはブラウザ内で処理され、注釈はブラウザのサイトデータに保存され、エクスポートはあなたが選んだ時だけ実行されます。wowMD が元ファイルを変更・アップロードすることはありません。

拡張は公開 GitHub Markdown ページをアウトライン・折りたたみ・コード・テーブル対応の構造化リーダーに変えます。wowMD Pro はローカル Markdown ファイル向けの完全なレビューワークスペースで、型付き注釈、ノート、バージョンまたぎのアンカー、Overall Review Map、4 つのエクスポート形式を備えています。

読者別の 4 つの出力：人向けのオフライン HTML、Obsidian 向けのレビュー済み Markdown、注釈のバックアップと再インポート用の Backup JSON、AI ツールや編集者への構造化ワークオーダーである Ticket JSON です。

wowMD はドキュメントに対して AI 分析を実行しません。AI は任意かつ外部です：Ticket JSON をエクスポートし、AI ツールに渡すかどうかはあなたが決めます。
