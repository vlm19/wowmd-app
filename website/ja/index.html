機能

読みやすさのために、必要な機能だけを。

アウトラインから開始

本文に入る前に、文書全体の構成を確認できます。

セクションの折りたたみ

長い文書では、大きな H2 セクションを個別に折りたためます。

コード表示

余白とハイライトで、コードブロックを読みやすく保ちます。

表の横スクロール

幅の広い表も、レイアウトを崩さず横にスクロールできます。

必要なときだけ表示

短い README やシンプルなページでは表示されず、邪魔をしません。

表示の整理

相対パスの画像をできるだけ正しく表示し、レンダリング後の Markdown を安全に整えます。

対応範囲

GitHub Markdown に集中し、対応範囲を明確に。

対応済み

  • 公開 GitHub リポジトリの README ページ
  • 公開 GitHub の .md ファイルページ
  • 公開 GitHub の .markdown ファイルページ
  • 右側パネルと全画面リーダー

未対応

  • プライベートリポジトリ
  • GitHub 以外の Web サイト
  • Issue、Pull Request、Wiki ページ
  • AI 要約、翻訳、クラウド同期

プライバシー

読むためのツールに、余計なデータはいりません。

個人情報は収集しません。

文書を第三者サービスへ送信しません。

AI 要約、クラウド解析、リモート設定は行いません。

閲覧履歴、Cookie、アカウント情報、ローカルファイルにはアクセスしません。

Better View をクリックするまで、Raw Markdown や GitHub API へのリクエストは行いません。
