プライバシーポリシー

最終更新日：2026年5月18日

wowMD は、公開 GitHub Markdown ページを読みやすくするローカル優先の Chrome 拡張機能です。

要約

wowMD は個人情報を収集せず、文書をアップロードせず、データを販売せず、閲覧履歴も追跡しません。

管理者

wowMD のプライバシーに関する問い合わせは、このサイトのフィードバックフォームからメンテナーへご連絡ください。

処理するデータ

拡張機能は、あなたが Better View を選んだときだけ、ブラウザ内でページ内容をローカルに読み取ります。アカウント情報、Cookie、閲覧履歴、ローカルファイル、非公開リポジトリの内容は収集しません。

目的と法的根拠

処理は、アウトライン、セクション折りたたみ、コード表示、表レイアウトなど、あなたが求めた読書機能を提供するために限られます。GDPR が適用される場合、根拠は依頼されたサービスの提供と、プライバシーを尊重するブラウザツールを運営する正当な利益です。

保存と保持

wowMD は読書アクティビティ用のリモートデータベースを持ちません。一時的な処理はブラウザセッション内で行われ、wowMD サーバーには送信されません。

共有と第三者

wowMD は読書データを販売または共有しません。Google Form からフィードバックを送信した場合、入力した情報は Google Forms によって処理され、回答内容や関連する Google メタデータが含まれることがあります。

Chrome Web Store と Limited Use

wowMD は、開示された読書機能を提供するためにのみブラウザ権限を使用します。Google API から情報を受け取る場合も、Chrome Web Store User Data Policy と Limited Use 要件に従います。

あなたの権利

欧州経済領域を含む居住地域によっては、アクセス、訂正、削除、制限、異議申し立て、データポータビリティなどの権利があります。wowMD は読書データをサーバーに保存しないため、多くの請求には収集しているものと収集していないものを説明して対応します。

子ども

wowMD は子どもを対象としておらず、子どもの個人情報を意図的に収集しません。

変更

wowMD のデータ処理方法が変わる場合は、その変更をリリースする前に本ポリシーを更新します。
