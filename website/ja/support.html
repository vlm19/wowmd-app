レビューループのガイドとフィードバック。

wowMDを際立たせるコンセプトから始めましょう：型付きレビュー・クロスバージョンサバイバル・Obsidian向けレビュー済みMarkdown・AIに渡せるチケット。

原文を変更せずに Markdown を開く

ファイル選択またはドラッグ＆ドロップでローカルの .md / .markdown を開くか、拡張機能から対応する公開 GitHub Markdown を引き継げます。

レビューはブラウザ内で行われ、原文には書き戻しません。レビュー済みコピーを保存すると、注釈を引き継いだ別の Obsidian 対応 .md が作成されます。

バージョン履歴から、現在の文書系統で作成されたブラウザ内の後継版を開き直せます。

型付きレビュー：4つの判断、単なる色ではない

wowMD でテキストをマークすると、次の行動を伴う判断が記録されます。これらのタイプはノートパネル、総合レビューマップ、Ticket JSON の凡例に反映されます。

疑問ありこの主張をレビュー。誤っている可能性があり、修正が必要かもしれない。
重要このキーポイントを保持し強調する。
確認済レビュー済みで正しい。アクション不要。

クロスバージョンサバイバル

ソースドキュメントが変更されると、wowMDは選択された引用と周辺コンテキストを使って、注釈を同じパッセージに再アンカーしようとします。パッセージが本当に消えた場合、マークは孤立し、Findで手動回復できます。

再アンカーは非破壊的です。wowMDは注釈の位置を再計算します。ソースファイルには書き戻しません。

保存・バックアップ・復旧

保存済み注釈とインポートした GitHub 文書コピーは、通常のブラウザキャッシュではなくサイトデータを使用します。ローカルファイルはセッション入力のままで、注釈は文書フィンガープリント別に保存されます。

サイトデータの消去、プライベートブラウズ、別のブラウザ・プロファイル・端末、ストレージの削除によりローカル作業が失われる場合があります。未保存のツールバー下書きも更新やクラッシュで失われます。

再インポート可能な注釈には Backup JSON、読みやすいレビュー文脈には Reviewed Markdown、長期保存には完成した成果物をエクスポートしてください。

エクスポート

HTMLエクスポートは人向け：構造、ハイライト、メモを含むオフラインで読める1つのファイルです。

レビュー済みMarkdownはObsidian向け：レビューcallout、タグ、propertiesを含む新しい.mdコピーです。元ファイルは編集せず、提案置換も適用しません。

バックアップJSONはバックアップと再インポート向け：生の注釈データです。

チケットJSONはAIまたは編集者向け：型付き判断から作る作業指示です。
