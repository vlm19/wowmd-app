wowMD Pro

ローカル Markdown の読書ワークスペース。

ブラウザでローカル Markdown ファイルを開き、重要な箇所をハイライトし、ノートを残し、文書をアップロードせずに読みやすいコピーを書き出せます。

wowMD Pro を開く 無料拡張機能が必要ですか？
早期アクセスは無料の場合があります ライフタイムライセンス予定 ローカル優先

ローカルファイル

端末上の Markdown ファイルを開く。

`.md` または `.markdown` ファイルを追加し、アウトライン、折りたたみ、読みやすいコード、表スクロールを備えた集中ワークスペースで読めます。

アプリを開く

ハイライトとノート

重要な箇所を文書のそばに残す。

重要な段落をマークし、短いノートを追加し、注釈データをローカルに保存します。将来の書き戻し機能を追加しない限り、元の Markdown は変更されません。

注釈を試す

読書ノート

重要なアイデアをローカルノートとして保存しました。

エクスポート

1 つの Markdown を読みやすいコピーに変換。

共有や保管用の完全なオフライン HTML、または Send to Kindle、Apple Books、Kobo など向けの EPUB を作成できます。

Pro からエクスポート

クリーン HTML

アプリランタイムを含まない、自己完結型で構造化されたオフライン HTML。

EPUB

主要な読書アプリ向けのナビゲーションメタデータ付きリフロー EPUB 3。

価格

価格確定前は Webapp を無料の早期アクセスとして提供する場合があります。予定している有料モデルは、低価格の一回払いライフタイムライセンスで、早割やプロモーション割引を提供する可能性があります。
